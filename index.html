🌵 Presque prêt !

Il manque la configuration Firebase pour que le jeu puisse synchroniser les parties entre joueurs.

  1. Va sur console.firebase.google.com et crée un projet gratuit.
  2. Dans le projet, ajoute une application Web (icône </>).
  3. Copie l'objet firebaseConfig qui s'affiche.
  4. Active Realtime Database dans le menu de gauche (mode test).
  5. Colle la config dans index.html, tout en haut du script, à la place des "REPLACE_ME".

🌵 Une erreur a empêché le jeu de démarrer

(Vérifie ta configuration Firebase en haut du script, et que la Realtime Database est bien activée.)
